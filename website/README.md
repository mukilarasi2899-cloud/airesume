# AI Resume Analyzer & Mock Interview Website

## 🚀 Quick Start

Your website is ready to use! Simply open `index.html` in any web browser.

### How to Run:
1. Navigate to `C:\ai-resume-interview-system\website`
2. Double-click `index.html` to open in your browser
3. Or right-click → "Open with" → Choose your browser

## ✨ Features

### 1. Resume Analyzer (`resume-analyzer.html`)
- **Upload Resume**: Drag & drop or click to upload PDF, DOCX, or TXT files
- **ATS Score**: Get instant score (0-100) on resume quality
- **Score Breakdown**: See detailed component scores
- **Skills Extraction**: Automatically detect technical and soft skills
- **Contact Info**: Extract email, phone, LinkedIn, GitHub
- **Recommendations**: Get actionable improvement suggestions
- **Job Matches**: See which roles best fit your skills

### 2. Mock Interview (`mock-interview.html`)
- **5 Job Roles Available**:
  - Software Engineer
  - Data Scientist
  - Frontend Developer
  - DevOps Engineer
  - Full Stack Developer
- **Customizable**: Choose 3-10 questions
- **Real-time Timer**: Track your interview duration
- **Instant Feedback**: Get scores and detailed evaluation
- **Performance Metrics**: Overall, technical, and communication scores
- **Improvement Tips**: Specific recommendations for better answers

### 3. Dashboard (`dashboard.html`)
- View all your resume analyses
- Track interview performance history
- See average scores and statistics
- Monitor your progress over time

## 📊 How It Works

### Resume Analysis Algorithm:
1. **Keyword Density (25%)**: Checks for crucial resume sections
2. **Skills Match (25%)**: Counts technical and soft skills
3. **Format Quality (20%)**: Evaluates structure and organization
4. **Experience (15%)**: Assesses work history
5. **Education (15%)**: Checks educational background

### Interview Evaluation:
1. **Keyword Coverage (40%)**: Matches expected technical terms
2. **Answer Length (20%)**: Ensures sufficient detail
3. **Structure (20%)**: Evaluates answer organization
4. **Technical Depth (20%)**: Checks for advanced concepts
